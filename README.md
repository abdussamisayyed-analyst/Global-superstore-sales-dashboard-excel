# 📊 Global Superstore Sales Dashboard (Excel)

## Project Overview
This project is an interactive Global Superstore Sales Dashboard created in Excel to analyze sales performance, customer segments, regional trends, and product insights.

## Features
- Sales Trend Analysis
- Region-wise Sales Distribution
- Customer Segment Analysis
- Top 10 Products Performance
- State-wise Sales Insights
- Interactive KPI Cards
- Dynamic Slicers & Filters

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- KPI Cards
- Slicers
- Conditional Formatting
